# Least-Square-Binary-Classification
Proyecto para la asignatura de Ampliación de Matemáticas III del Grado en Estadística de la UVa

# Descripción
El problema consiste en predecir si un tumor es benigno o maligno, a partir de un conjunto de datos de tumores con 30 características numéricas reales, aplicando clasificación binaria por mínimos cuadrados y regresión multilineal.
